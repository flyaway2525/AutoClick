# AutoClick

OpenCV の画像認識（テンプレートマッチング）を使用して、画面上の特定アイコン・ボタンを自動的にクリックし続けるツールです。  
Windows のタスクトレイに常駐し、トレイアイコンのクリックで ON / OFF を切り替えられます。

---

## 特徴

- **画像認識ベースのクリック** — スクリーンショットと登録テンプレート画像を比較し、一致箇所を自動クリック
- **マルチスケール対応** — 0.8× ～ 1.2× の範囲でスケールを変えながらマッチングするため、画面解像度や DPI が多少異なっても検出可能
- **重複クリック防止** — 同じボタン領域を1巡で複数回クリックしないよう近傍チェックを実施
- **2つのクリック方式** — 見えている間は毎周クリックする「毎周クリック」と、出てきた時に1回だけクリックする「出現ごとに1回」を選べる
- **高速な2段階検索** — 縮小した画面で候補を探し、候補の周りだけを元の解像度で確かめる
- **マスク画像対応** — `xxx.mask.png` を置くと、背景が透けるアイコンでも本体だけで照合できる
- **マルチモニター対応** — `mss` で全モニターを撮影（未インストール時はメインモニターのみ）
- **画面上の状態表示** — ゲーム中でも ON / OFF が分かるよう、画面の隅に小さく表示（クリックは透過）
- **タスクトレイ常駐** — ウィンドウなしでバックグラウンド動作。赤丸（停止）／緑丸（動作中）でひと目で状態確認
- **ホットキー** — F7 で通常の ON / OFF、F8 で雪だるま自動、F9 でクッキング自動、F10 で即停止、F1 でキー設定を画面に表示
- **ログウィンドウ** — トレイメニューから操作ログをリアルタイム確認
- **二重起動防止** — Windows Mutex により同一プロセスの重複起動をブロック

## セットアップ

### 必要環境

- Windows 10 / 11
- Python 3.10 以上

### インストール手順

まず以下を実行してください（推奨）。

```bat
setup_venv.bat
```

手動で行う場合:

```bat
:: 仮想環境を作成
python -m venv .venv

:: 仮想環境を有効化
.venv\Scripts\activate

:: 依存パッケージをインストール
pip install -r requirements.txt
```

> `tkinter` は Python 標準ライブラリに含まれているため、別途インストール不要です。

## 使い方

### 1. テンプレート画像を用意する

クリックしたいボタン・アイコンをスクリーンショットで切り抜き、PNG ファイルとして `images/` フォルダに配置します。

```
images/
└── my_button.png   ← 追加するテンプレート（ボタン名は my_button）
```

### 2. `autoclick_config.json` の設定を編集する

通常はトレイメニューの **設定** から UI で編集します。  
（必要なら `autoclick_config.json` を直接編集しても動作します）

```json
{
    "button_names": [],
    "templates": ["my_button.png"],
    "candidate_templates": ["C:/GitHub/AutoClick/AutoClick/images/my_button.png"],
    "threshold": 0.7,
    "click_interval": 0.2,
    "set_interval": 0.2,
    "scale_min": 0.8,
    "scale_max": 1.2,
    "scale_step": 0.05,
    "min_template_size": 10,
    "click_mode": "repeat",
    "rearm_delay": 0.3,
    "search_downscale": 0.5
}
```

| パラメータ | 説明 | 推奨値 |
|---|---|---|
| `templates` | 検出対象の画像ファイル名一覧 | — |
| `candidate_templates` | 設定UIの候補画像一覧（絶対パス推奨） | — |
| `button_names` | 旧方式との互換項目（通常は空でOK） | — |
| `threshold` | マッチング精度の下限。低すぎると誤検知、高すぎると見逃し | `0.7` ～ `0.85` |
| `click_interval` | 各クリック後のスリープ秒数。0 にすると連打 | `0.1` ～ `0.5` |
| `set_interval` | 全テンプレートを1巡した後のスリープ秒数 | `0.1` ～ `1.0` |
| `scale_min` / `scale_max` / `scale_step` | マルチスケール探索の範囲・刻み | `0.8` / `1.2` / `0.05` |
| `min_template_size` | スケール後の最小テンプレートサイズ（px） | `10` |
| `click_mode` | `repeat`: 見えている間は毎周クリック / `once`: 出現ごとに1回だけクリック | — |
| `rearm_delay` | `once` のとき、対象が消えてから再びクリック可能になるまでの秒数 | `0.3` |
| `search_downscale` | 粗い検索で画面を縮小する倍率。小さいほど速いが見逃しやすい（1.0 で縮小なし） | `0.5` |

設定変更はトレイメニューの **設定** から設定UIを開き、**保存して適用** で即時反映されます。  
**デフォルトに戻す** でフォーム値を初期設定に戻せます（保存はまだ行われません）。
設定UIでは、**参照...** で候補画像を登録し、**選択画像を追加** で有効化対象へ追加します。候補一覧・有効化対象一覧の両方から不要画像を除外できます。  
有効化対象一覧はファイル名のみ表示し、マウスを乗せるとフルパスを確認できます。

### 3. アプリを起動する（`.venv` 必須）

```bat
start.bat
```

`start.bat` / `start_test_button.bat` はグローバル Python では実行しません。  
`.venv` が無い場合は先に `setup_venv.bat` を実行してください。

タスクバー右下のトレイエリアに **赤丸アイコン**（停止状態）が表示されます。

### 4. クリックを開始 / 停止する

| 操作 | 内容 |
|---|---|
| トレイアイコンをクリック | 動作中なら停止、停止中なら通常の AutoClick を開始（ダブルクリックしても1回分） |
| トレイアイコン右クリック → **通常の AutoClick: 開始 / 停止** | F7 と同じ |
| トレイアイコン右クリック → **すぐ停止** | F10 と同じ |
| **F1 キー** / 右クリック → **キー設定を表示** | キー設定を画面に6秒表示（もう一度押すと消える）。動作中のモードは色付きで表示 |
| **F7 キー** | 通常の AutoClick の ON / OFF |
| **F8 キー** / 右クリック → **雪だるま自動** | 雪だるま自動の開始 / 雪だるまを回収したら停止 |
| **F9 キー** / 右クリック → **クッキング自動** | クッキング自動の開始 / 料理を終えたら停止 |
| **F10 キー** | 何が動いていてもすぐ停止（以前は ESC でしたが、ゲームでメニューを閉じる時に止まってしまうので変えました） |

キーのルールはどのモードも同じです。

- 止まっている時に押す → そのモードを開始
- 動いているモードのキーを押す → 停止（クッキング・雪だるまは「作りかけを終えたら停止」→ もう一度で「すぐ停止」）
- **別のモードが動いている時に押す → 何もしません**（同時には動かしません）。画面左上に「〇〇が動作中です」と出ます
- キーを押しっぱなしにしても1回分しか反応しません

トレイメニューの文言は、押した時に起きること（開始 / 料理を終えたら停止 / すぐ停止）に合わせて変わります。
| マウスを画面の隅へ移動 | 緊急停止（pyautogui のフェイルセーフ） |
| トレイアイコン右クリック → **設定** | 設定UIを開く（保存時に `autoclick_config.json` を再読込） |
| トレイアイコン右クリック → **ログを開く** | ログウィンドウを表示 |
| トレイアイコン右クリック → **終了** | アプリを終了 |

アイコンの色が **緑丸**（▶ 付き）に変わればクリック動作中です。

## 動作の仕組み

```
起動
 └─ タスクトレイアイコン生成
       │
       ▼ ON にすると
    worker スレッドを生成
       │
       ▼ ループ（is_running() == True の間）
    1. mss で全モニターのスクリーンショット取得（無ければ pyautogui）
    2. グレースケール変換
    3. 各テンプレート・各倍率について
       a. 縮小した画面で粗く照合し、候補を最大50件まで絞る
       b. 候補の周りだけを元の解像度で照合（マスクがあればマスク付き）
       c. threshold 以上のものを採用
    4. スコア降順にソートし、近傍重複を除く
    5. 順次クリック（「出現ごとに1回」なら、クリック済みでまだ見えている対象は飛ばす）
    6. click_interval 待機
    7. 全テンプレート完了後 set_interval 待機
    8. 1 へ戻る
```

マルチスケールは `np.arange(0.8, 1.21, 0.05)` の9段階（0.80, 0.85, … 1.20）でテンプレートをリサイズしてマッチングします。

### マスク画像

アイコンの背後にゲーム画面が透けている場合など、背景が変わるとスコアが下がることがあります。
テンプレートと**同じサイズ**の白黒画像を `元の名前.mask.png` として同じフォルダに置くと、
白い部分だけで照合します（例: `images/flai_spatula.png` → `images/flai_spatula.mask.png`）。

## フライ返しアイコンを自動クリックする

フライ返しアイコン（`images/flai_spatula.png`）は候補画像に登録済みです。

1. トレイメニューの **設定** を開く
2. 候補画像から `flai_spatula.png` を選び **有効化へ追加**（不要なら `button_1.png` は除外）
3. 次のように設定して **保存して適用**

| 項目 | 値 |
|---|---|
| 一致しきい値 | `0.82` |
| クリック方式 | 出現ごとに1回 |
| クリック間隔 | `0` |
| 周回待機 | `0.04` |
| 再クリック待ち | `0.3` |

ゲームの解像度を変えてアイコンの大きさが変わっても、最小倍率～最大倍率の範囲なら検出できます。

## クッキング自動（順番にクリック）

料理のボタンを決まった順番で押すための専用モードです。通常の AutoClick とは別に ON / OFF できます。

| 手順 | 画像 | 動き |
|---|---|---|
| 1 | `images/cook_1_pan.png` | フライパンのアイコン（コンロの上） |
| 2 | `images/cook_2_start.png` | 「クッキング開始」ボタン（画面に1つ） |
| 3 | `images/flai_spatula.png` | フライ返し（出てくるたびに押す） |
| 4 | `images/cook_4_mitten.png` | ミトン（これで料理完了） |

### ON / OFF

| 状態 | F9 を押すと | アイコン |
|---|---|---|
| 停止中 | 開始 | オレンジ |
| 動作中 | **作りかけの料理をミトンまで終えてから止まる**（新しい料理は始めない） | 黄色 |
| 終了待ち中 | すぐ止まる | — |

トレイメニューの **クッキング自動** も同じ動きです。F10 はいつでもすぐ止まります。

### 画面上の状態表示（オーバーレイ）

ゲーム中はタスクトレイが見えないので、ON / OFF を切り替えると**画面の左上に小さく状態を表示**します。

| 表示 | 意味 |
|---|---|
| ● オレンジ「クッキング自動 ON」 | 動作中 |
| ● 黄色「料理を終えたら停止」 | 終了待ち（作りかけの料理を終えたら止まる） |
| ● 水色「雪だるま自動 ON」 | 雪だるま自動が動作中 |
| ● 緑「AutoClick ON」 | 通常の AutoClick 動作中 |
| ● 赤「AutoClick 停止」 | 2秒表示して消える |

- 表示の上をクリックしても、下のゲームにそのまま届きます
- 表示はボタン探しの画面撮影には写りません（表示の下にボタンがあっても見つけられます）。
  そのため、スクリーンショットや録画・配信にも写りません（Windows 10 2004 以降）
- 位置や不透明度は `tray_app.py` の先頭の `OVERLAY_POSITION`（`top-left` / `top-right` / `bottom-left` / `bottom-right`）、`OVERLAY_ALPHA` で変えられます。`OVERLAY_ENABLED = False` で表示しません
- ゲームが**排他的フルスクリーン**だと上に表示できません。ボーダーレス（ウィンドウ）モードで使ってください

### 動き

- 今の手順のボタンを押し、**次の手順のボタンが見えたら次へ進みます**。4 の次は 1 に戻ります
- **コンロが複数あっても大丈夫です。** ボタンの出た位置でコンロを見分けて、コンロごとに順番を守ります
- 「クッキング開始」は画面に1つしか出ないので、あるコンロのフライパンを押したら、
  「クッキング開始」を押し終えるまで別のコンロのフライパンは押しません
- 途中で ON にしても、見えているボタンの手順から始めます
- **連打はしません。** ボタンは1回出るごとに1回だけ押します。押したあと `sequence_retry_delay`（5秒）たってもまだ残っている時だけ押し直します（雪マークだけは素早く押します）
- **押す直前に、その場所をもう一度撮って確かめます。** 画面が切り替わっていたら押しません（前の画面の位置で別のボタンを押さないため）
- 押したあとは `sequence_after_click`（0.4秒）待ってから次のボタンを探します
- 一度ボタンを見つけたら、その大きさの近くだけを探して速くします

### 設定

手順は `autoclick_config.json` の `cooking_steps` で変えられます（上から順）。手順ごとに一致しきい値（`threshold`）や押し直し間隔（`retry`）も指定できます。コンロの上ではなく画面に1つだけ出るボタンには `"shared": true` を付けます。

```json
"cooking_steps": [
  "images/cook_1_pan.png",
  {"template": "images/cook_2_start.png", "shared": true},
  {"template": "images/flai_spatula.png", "retry": 0.3},
  "images/cook_4_mitten.png"
],
"cooking_stove_radius": 60,

"sequence_threshold": 0.70,
"sequence_rearm_delay": 0.3,
"sequence_retry_delay": 5.0,
"sequence_after_click": 0.4,
"sequence_lost_timeout": 30.0,
"sequence_interval": 0.05
```

| 項目 | 説明 |
|---|---|
| `cooking_stove_radius` | アイコンの中心がこの距離（px）以内なら同じコンロとみなす（雪だるまは `snowman_stove_radius`） |
| `sequence_threshold` | 一致しきい値（手順ごとの `threshold` が優先） |
| `sequence_rearm_delay` | ボタンが消えてからこの秒数たったら「新しく出た」とみなす |
| `sequence_retry_delay` | 押したのにまだ見えている時、押し直すまでの秒数（短いと連打になる） |
| `sequence_after_click` | 押したあと、画面が切り替わるのを待つ秒数 |
| `sequence_lost_timeout` | コンロのボタンがこの秒数見えなければ、そのコンロを忘れる（終了待ちもこれで終わる） |
| `sequence_interval` | 画面チェックごとの待ち秒数 |

`sequence_*` はクッキング自動と雪だるま自動の共通設定です（以前の `cooking_retry_delay` などの名前も読めます）。
一致しきい値などは**通常の AutoClick の設定（設定画面）とは別**なので、設定画面で通常モードを調整してもクッキング・雪だるまには影響しません。
ただし倍率（最小・最大・刻み）、最小画像サイズ、検索縮小率は画面の大きさに関わるので共通です。
動作中に設定画面で保存しても、これらが変わらなければ作りかけの料理の状態はそのまま続きます。

## 雪だるま自動（順番にクリック）

雪だるまを作るボタンを順番に押す専用モードです。クッキング自動と同じ仕組みで動きます。

| 手順 | 画像 | 動き |
|---|---|---|
| 1 | `images/snow_1_place.png` | 雪玉を置く（台の上のアイコン） |
| 2 | `images/snow_2_operate.png` | 雪玉を操作する（雪の結晶のアイコン） |
| 3 | `images/snow_3_flake.png` | 雪マークを**全部**素早く押す（消えるまで 0.15秒ごと） |
| 4 | `images/snow_4_collect.png` | 回収（雪だるまのアイコン） |

- 2 → 3 を何度か繰り返します。3 が終わって 2 のアイコンがまた出たら、もう一度押します
- 4 のアイコンが見えたら回収して、次の雪玉（1）に戻ります
- **F8** またはトレイメニューの **雪だるま自動** で切り替え（動作中はアイコンが水色）
- F8 の動きは F9 と同じです。動作中に押すと**作りかけの雪だるまを回収してから止まり**、もう一度押すとすぐ止まります
- 雪玉が大きくなるとアイコンの位置が上にずれるので、同じ台とみなす距離 `snowman_stove_radius` は 150px にしています

手順は `autoclick_config.json` の `snowman_steps` で変えられます。

| 手順のオプション | 意味 |
|---|---|
| `"shared": true` | 台の上ではなく画面に出るボタン（クッキング開始、雪マーク） |
| `"all": true` | 見つかったものを全部押す（雪マーク） |
| `"repeat": true` | 次の shared 手順が終わったら、もう一度押す（雪玉の操作） |
| `"retry": 秒` | 見えている間、この秒数ごとに押し直す |

### モードは同時に動きません

通常の AutoClick（F7）、雪だるま自動（F8）、クッキング自動（F9）は、どれか1つだけ動きます。
動作中に別のモードのキーを押しても開始しません（ログに理由が出ます）。先に今のモードを止めてください。

## テストツール

実際の画面でテンプレートマッチングが機能するか確認するための専用ウィンドウです。

```bat
start_test_button.bat
```

`test_tools/test_button_window.py` が起動し、**Left Button**（緑）と **Right Button**（青）が3つずつ表示されます。  
対応するテンプレート画像（`images/test-left-button.png`、`images/test-right-button.png`）を用意し、設定UIで `templates` に追加した状態で AutoClick を ON にすると、これらのボタンが自動クリックされ、ウィンドウ内のカウンタが増加します。

## トラブルシューティング

| 症状 | 確認事項 |
|---|---|
| テンプレートが見つからない (`見つからず` ログ) | `threshold` を下げる / テンプレート画像を撮り直す |
| 誤った場所をクリックする | `threshold` を上げる / テンプレート画像を小さく切り抜きすぎていないか確認 |
| 起動しても何も起きない | `.venv` が正しく作成されているか確認。`start.bat` を右クリック→「管理者として実行」を試す |
| 二重起動エラー | タスクトレイに既にアイコンがないか確認 |
| 動いているはずなのに何も押さない | 画面左上に「ボタンが N 秒見つかりません」と出ていないか確認。出ていれば、ボタンが画面に出ていない（別の画面・メニューを開いている、カメラが動いた等）か、画像が合っていません |
| 勝手に止まる | `autoclick.log` の「停止（〇〇）」に止めた理由（F10 キー・メニュー・トレイアイコンのクリック等）が残ります。理由が無く「〇〇がないので止めます」の時は終了待ちで止まっています |
| F7〜F10 が効かない | アクティブウィンドウが管理者権限のアプリの場合、`tray_app.py` も管理者権限で起動する |
| 起動時にエラーが出た | メッセージの内容は `autoclick_error.log` にも残ります |

## 配布用 exe の作り方

Python が入っていない PC でも動く exe 版を作れます。

**配り方（GitHub Releases・クラウドストレージ）、配る前の動作確認、受け取った人の手順、更新の仕方は [DISTRIBUTION.md](DISTRIBUTION.md) にまとめています。**

```bat
build_exe.bat
```

`dist\AutoClick.zip`（約 50MB）ができます。これを渡せば、相手は展開して `AutoClick.exe` をダブルクリックするだけで使えます。
使い方は zip の中の `はじめにお読みください.txt`（元は `packaging\README_dist.txt`）に書いてあります。

- 設定（`autoclick_config.json`）・画像（`images\`）・ログは **exe と同じフォルダ**に置かれます。画像を差し替えれば、exe を作り直さなくても反映されます
- 同梱ライブラリのライセンスは `THIRD_PARTY_LICENSES.txt` と `licenses\` に自動で集めます（`packaging\collect_licenses.py`）
- PyAutoGUI が使う GPL ライセンスのライブラリ（PyMsgBox・MouseInfo）と、OpenCV の動画用 FFmpeg は使わないので exe に入れていません
- 署名していないため、初回は Windows SmartScreen の警告が出ます（「詳細情報」→「実行」）
